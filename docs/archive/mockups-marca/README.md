# Comparações de marca arquivadas

Estas páginas apresentavam três propostas visuais de marca em `/mockups`. Foram retiradas do build de produção após o experimento H4 (relatório `docs/ops/2026-10-28-spec010-fidelidade2/fonte-build/h4/RELATORIO-fonte-build-h4.md`, no repositório do workspace bullq2), que identificou falhas intermitentes associadas às chamadas de fontes dessas páginas.

Para consultá-las, abra os arquivos `.tsx.txt`. Para executá-las novamente, restaure suas extensões e caminhos em uma cópia de desenvolvimento e instale as dependências do projeto; isso reintroduz as rotas e chamadas de fonte no build.
